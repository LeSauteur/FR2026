# Домиан Hub — карта сервиса и дорожная карта

## Принцип

Сервис строится вокруг **сущностей** (пользователь, офис, статья, задача, расчёт, объявление, заявка), а не вокруг HTML-страниц. Права проверяет сервер. Во фронтенде нет ни паролей, ни данных, которые не положены текущему пользователю.

```
                    ДОМИАН HUB
                        │
       ┌────────────────┼────────────────┐
   МОЯ РАБОТА        МОЙ ОФИС          ЗНАНИЯ
   7 дней ✓          Карточка ✓       Статьи ✓
   Прогресс ✓        Реквизиты ✓      Поиск ✓
                     Сеть ✓           Документы (4)
       └──────────┐     │     ┌──────────┘
                  ▼     ▼     ▼
                 ГЛАВНАЯ ✓ (что важно сегодня)
                        │
     ┌──────────────┬───┴──────────┬──────────────┐
  ФИНАНСЫ (3)   КАЛЬКУЛЯТОРЫ ✓  ОБУЧЕНИЕ (2)   ПОДДЕРЖКА ✓
  Royalty       Роялти ✓        HR (2)         Заявки ✓
  Plans         Мотивация ✓                    Объявления ✓
  Dom2 A4       A4, ведомость (3)
```

✓ — есть в каркасе v0.1, (N) — этап дорожной карты.

## Роли

| Роль | Что видит |
|---|---|
| `superadmin` | всё, журнал аудита |
| `franchise` | все офисы и реквизиты, все заявки, пользователи, служебные статьи |
| `editor` | свой раздел базы знаний (редактор — этап 1), служебные статьи |
| `owner` | свои офисы (через привязку), общая база, свои расчёты и заявки |
| `manager` | офис, к которому привязан, включая реквизиты |
| `readonly` | общая база без реквизитов |

Привязка к офису (`office_memberships`) отдельна от роли: один собственник — несколько офисов.

## Этапы

### Этап 0 — безопасность (сейчас, без программирования)
См. `REVISION.md`, раздел «Срочно». Закрыть репозитории, сменить секреты, почистить историю.

### Этап 1 — рабочая основа
- Форма создания пользователей и привязки к офисам, смена пароля, сброс пароля отделом.
- Редактор статей (для `editor` — только свой раздел), версии статей (`article_versions`).
- Импорт officeip → БД (скрипт, запускается только на закрытом сервере).
- Разбор Instrukciya на статьи.
- Полнотекстовый поиск SQLite FTS5 вместо `LIKE`.
- Хостинг в РФ, HTTPS, `secureCookies: true`, резервные копии базы.

### Этап 2 — рабочий кабинет
Обучение (каталог + «пройдено»), HR (этапы приёма без документов), календарь с добавлением событий, объявления с публикацией из интерфейса.

### Этап 3 — финансы
Экономика офиса A4 и ведомость из Dom2 (с тестами), Royalty и Plans, история роялти по месяцам.

### Этап 4 — документы
Замена франшизной папки: файлы, версии, актуальность, защищённые ссылки, ревизия для отдела.

## Сознательно НЕ делаем
CRM недвижимости, мессенджер, кадровую систему с паспортами, бухгалтерию, мобильное приложение. Сайт адаптивный — этого достаточно.
