# Домиан Hub — кабинет собственника (FR2026)

Приватный сервис для собственников франшизы Домиан. Серверный режим остаётся локальным каркасом v0.1; для презентаций отдельно публикуется статическая демонстрация на GitHub Pages.

## Онлайн-демо

Демо открывается по адресу: **https://lesauteur.github.io/FR2026/**

На экране входа выбирается роль; пароль в демонстрационном режиме временно отключён. Все люди, офисы и реквизиты вымышлены. Отметки, заявки и сохранённые расчёты остаются только в `localStorage` браузера и не отправляются на сервер.

- Ревизия старых сервисов и проверка отчёта ChatGPT → [docs/REVISION.md](docs/REVISION.md)
- Карта сервиса, роли, перенос, этапы → [docs/ROADMAP.md](docs/ROADMAP.md)

## Запуск

Нужен только Node.js 24+. Внешних зависимостей нет, `npm install` не нужен.

```bash
npm run seed      # создать локальную базу с демо-данными
npm start         # http://localhost:5180
npm test          # тесты расчётов, прав доступа и безопасности
npm run reset     # пересоздать базу (пароли сменятся)
```

Логины и пароли демо-пользователей генерируются при `seed` и лежат в `data/dev-credentials.txt`:
`admin`, `franchise`, `editor-hr`, `owner1` (два офиса), `owner2` (один офис), `manager1`.

Все офисы, люди и реквизиты в демо-данных **вымышлены**.

## Устройство

```
server/        HTTP-сервер, API, авторизация, права, аудит
  schema.sql   схема БД (SQLite)
  app.js       маршруты API и раздача статики
  auth.js      scrypt-пароли, сессии (HttpOnly cookie, в БД — только хэш токена), лимит попыток
  access.js    ВСЕ проверки прав — только здесь
shared/        чистые расчётные функции — общие для браузера, сервера и тестов
  policies/    версионные политики (royalty-2026.1, motivation-2026.1)
public/        интерфейс: ES-модули без сборки
scripts/       seed и импорт из репозиториев-доноров
seed/          демо-контент и перенесённые «7 дней»
tests/         node --test
data/          локальная база и учётки — НЕ в git
```

## Правила безопасности

1. Во фронтенде нет паролей, токенов, списков офисов и реквизитов. Это проверяет тест.
2. Каждый запрос к API проверяет сессию и права на сервере. Чужой офис для собственника не существует (404).
3. Изменяющие запросы принимаются только со своего Origin; чужой Host отклоняется.
4. CSP без `unsafe-inline`: никаких инлайн-скриптов и `style="…"`.
5. Просмотр реквизитов, входы и смена статусов пишутся в `audit_log`.
6. Реальные данные сети загружаются **только** на закрытый сервер (этап 1), никогда — в репозиторий.

## Публикация демо

GitHub Actions сначала запускает тесты, затем собирает Pages-артефакт из `public/`, `shared/` и только вымышленных файлов `seed/*.json`. GitHub Pages не запускает Node.js и SQLite, поэтому в онлайн-демо API эмулируется в браузере. Обычный серверный запуск продолжает использовать SQLite, сессии и парольную защиту.
